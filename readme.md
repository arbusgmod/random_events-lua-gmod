# random_events

Official repository for the **random_events** addon for Garry's Mod.

## 📌 Overview

This addon completely overhauls the visual interface of Garry's Mod, giving the game a fresh and modern look. It also introduces a system for triggering custom random events on the map.

## 🎮 Console Commands

| Command | Description | 
| ----- | ----- | 
| `random_event` | Triggers a random event on the map. | 
| `random_event_stop` | Forcefully stops the currently active random event. | 

## 🎨 Visual Overhaul & Interface

The addon redesigns almost the entire default Garry's Mod UI.

> ⚠️ **IMPORTANT NOTE (Options Menu Bug):**
>
> There is currently a known bug with the **Options** menu in the new UI.
>
> **Workaround:**
> If you need to configure your settings, please switch to the **original (default) Garry's Mod main menu** and access the Options from there.

# random_events

Official repository for the **random_events** addon for Garry's Mod.

## 📌 Overview

This addon completely overhauls the visual interface of Garry's Mod, giving the game a fresh and modern look, and introduces a system for triggering custom random events.

## 🎮 Console Commands

| Command | Description | 
| ----- | ----- | 
| `random_event` | Triggers a random event on the map. | 
| `random_event_stop` | Forcefully stops the currently active random event. | 

## 🎨 Visual Overhaul & Interface

The addon redesigns almost the entire default Garry's Mod UI for a cleaner and updated user experience.

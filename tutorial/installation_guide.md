# Installation Guide for random_events

Hello! This guide will walk you through the process of installing the **random_events** addon for Garry's Mod.

## 📥 How to Download and Install

### Step 1: Download from Releases

1. Open the GitHub repository for this addon.

2. **Important:** Do **NOT** click "Download ZIP" directly from the source code button.

3. On the right side of the repository page, click on the **Releases** tab.

4. Locate the latest release and download the archive/folder for the addon.

### Step 2: Extract the Files

1. Extract (unzip) the downloaded archive using WinRAR, 7-Zip, or the built-in system unzipper.

### Step 3: Locate your Garry's Mod Addons Directory

1. Open **Steam**.

2. Go to your Library and right-click on **Garry's Mod**.

3. Select **Manage** $\rightarrow$ **Browse local files**.

4. In the opened File Explorer, go to the `garrysmod` folder, and then open the `addons` folder.

### Step 4: Install the Addon

1. Move the extracted `random_events` folder into your `addons` directory.

2. Ensure that your folder structure looks exactly like this:

   ```
   Steam/steamapps/common/GarrysMod/garrysmod/addons/random_events/lua/autorun/random_events.lua
   
   ```

3. If the file structure matches the path above, congratulations! The addon is successfully installed.

## ⚠️ Important Compatibility Warning

> **Note:** This addon may conflict with certain Steam Workshop addons as it is not fully optimized to work alongside all third-party modifications. If you encounter issues, try temporarily disabling other addons.

Launch the game and enjoy testing the addon!
